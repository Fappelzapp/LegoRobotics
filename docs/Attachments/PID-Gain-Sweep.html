PID Lab.

Your Python ran on the laptop. This page replays the resulting samples — it does not calculate a different PID in JavaScript.

Simulation is not a robot test. No hub was contacted. Geometry, motor polarity and lag are unverified. No mat collisions, forces, battery or accurate braking model. Each route starts independently at the local origin.

Start here — three steps

  1. Choose a route below. demo drives crooked, corrects heading, turns to 90°, and reverses.
  2. Press Play. The pink path and error plot use the same clock.
  3. Drag the time slider to inspect one instant. Change Python/config settings and rerun the terminal command to calculate a new simulation.
