# Dashboard

Live indexes for the vault. Every table below is rendered by **Obsidian Bases** — it reads
frontmatter directly, needs no community plugin, and updates as notes change. Curated
navigation stays in [[docs/Home|Home]].

> [!tip] What to use where
> **Dashboard** answers *"what exists and what changed?"* · [[docs/Home|Home]] answers
> *"where do I start?"* · [[docs/Backlog|Backlog]] answers *"what is left to do?"* ·
> [[docs/Journal/Agent Log|Agent log]] records *"what was done and how was it checked?"*
